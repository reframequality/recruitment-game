# The Modern IT Recruitment Game

A snakes-and-ladders style satire of the modern IT hiring process. Roll the dice, dodge the ATS, and try to beat 100:1 odds.

Plain HTML, CSS and JavaScript. No build step, no dependencies. Open `index.html` in a browser.

## Files

- `index.html` - page structure
- `styles.css` - styling
- `data.js` - all the content: snake, ladder and square text (edit the jokes here)
- `game.js` - game logic and rendering
- `IMPROVEMENTS.md` - ideas backlog
